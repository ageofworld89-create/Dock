# Rainmeter Left Dock

Левая док-панель для Rainmeter.

## Файлы
- `Dock.ini` — основной скин и разметка
- `Hover.lua` — анимация наведения на Lua
- `*.png` — иконки кнопок (`instagram.png`, `search.png`, `telegram.png`, `tiktok.png`, `yandex.png`, `youtube.png`)

## Установка
1. В папке скинов `Документы\Rainmeter\Skins\` создай папку `Dock`.
2. Кинь туда `Dock.ini` и `Hover.lua`.
3. Внутри папки `Dock` создай папку `images` (или `icons` — как прописано в путях внутри `Dock.ini`) и перенеси туда все `.png` картинки.
4. В трее кликни по Rainmeter ПКМ -> **Обновить всё**.
5. В окне управления выбери `Dock` -> `Dock.ini` и жми **Загрузить**.
